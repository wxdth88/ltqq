# 联通十周年 · 抢 QQ超级会员（Windows 桌面版）

自动抢「充值享会员」活动的 **QQ超级会员 · 充300送一年** 名额，只做锁单抢名额，充值自己在手机上完成。

## 一、先装 Python（一次性）

1. 打开 https://www.python.org/downloads/
2. 下载 **Python 3.10/3.11/3.12**，安装时**务必勾选** `Add python.exe to PATH`
3. 装完打开命令行（Win+R 输入 `cmd`），输入 `python --version` 能显示版本号即可

> Windows 10/11 一般已内置 WebView2 运行时（登录窗口依赖）。若报错提示缺少 WebView2，去 https://developer.microsoft.com/microsoft-edge/webview2/ 装一下。

## 二、运行（两种方式任选）

### 方式 A：直接运行（简单）
```
pip install requests pywebview
python lt_qqsvip_windows.py
```

### 方式 B：打成 exe（可拷给别人，双击即用）
双击运行 `build.bat`，完成后在 `dist\联通抢会员.exe`。

## 三、使用步骤

1. **登录**：点「📱 登录」→ 软件弹出内置浏览器 → 点「请登录」→ 拖动滑块 → 输手机号 → 收短信输验证码 → 登录。登录成功后点浏览器**右下角红按钮「✅ 完成登录」**，软件自动抓取并保存 Cookie。
2. **测试**：点「① 测试登录」确认号码、资格、库存正常。
3. **定时**：点「③ 开始每日自动抢」，每天 10:00:00 到点自动锁单。
4. **收尾**：锁单成功会响铃+弹窗 → 你打开手机活动页，完成充值（收短信验证码、付 300 元）。

## 四、重要说明

- **登录那一下**需要你手动拖滑块 + 输短信验证码，这是联通的反机器人验证，任何软件都无法替代。
- **Cookie 会过期**（通常几小时~1天）。软件会提示失效，失效后重新点一次「登录」即可（比抓包方便很多）。
- **昨天已售罄**属正常，10 点开抢后热门会员很快抢光，脚本靠秒级到点抢。
- 抢购时间、giftCode、提前量都能在界面改。默认 `26101311`（QQ超级会员·充300送一年）。

## 五、常见问题

| 现象 | 处理 |
|---|---|
| 提示"未安装 pywebview" | 命令行执行 `pip install pywebview` |
| 登录窗口没出现 | 检查 WebView2 是否安装（见第一部分） |
| 点「完成登录」提示未读到 Cookie | 确认已在网页里登录成功（看到手机号），再点 |
| 到点没反应 | 确认已点「开始每日自动抢」，且电脑没休眠；建议关闭休眠/睡眠 |
| 锁单返回 code=3 | Cookie 失效，重新「登录」 |
| 锁单返回 B0102 | 当天库存已售罄 |
